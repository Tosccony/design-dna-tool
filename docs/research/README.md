# Research Archive

Markdown notes from `/research` sessions — one file per session.

Notes are committed because they're library assets: each note represents real research effort, captures vertical-specific patterns, and pays off on future projects in the same vertical (the prior-research-lookup behavior in `/new-mockup` will surface relevant prior notes when starting fresh).

**File naming:** `<slug>-<YYYY-MM-DD>.md` where slug is a kebab-case keyword for the vertical or brief (e.g., `printmaker-merch-2026-04-29.md`, `law-firm-ip-2026-05-12.md`).

**Structure:** see `docs/plans/2026-04-29-website-research-design.md` (output shape section) for the canonical layout.

**Don't:** edit notes by hand to "polish" them. The dated record is the value — outdated insights are themselves a signal. Run a fresh `/research` session if a note has gone stale.
